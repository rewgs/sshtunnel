# sshtunnel

This is a fork of [https://github.com/pahaz/sshtunnel](@pahaz's `sshtunnel`). It seems that development on that version has stalled, so I'm working to modernize it here.

Supports Python v3.8 and up.

The original library was a single file, which at this moment is [still preserved](./sshtunnel/sshtunnel.py). This fork is splitting it up in a more modern fashion; as a result, all other files in the [`sshtunnel`](./sshtunnel) directory are part of the fork.
